# goit-ds-hw-03

Домашнє завдання: CRUD у MongoDB через PyMongo та скрапінг https://quotes.toscrape.com/.

## Встановлення (PowerShell, Python 3.10+)

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Заповніть `MONGODB_URI` у `.env` даними Atlas. Для цього проєкту локальний `.env` вже налаштовано. У Atlas користувач має мати права читання/запису, а поточна IP-адреса — бути дозволена в Network Access. Паролі зі спеціальними символами в URI потрібно URL-кодувати. `.env` виключений із Git та архіву.

## Завдання 1

```powershell
.\.venv\Scripts\python.exe main.py
```

Меню дозволяє створити кота, переглянути всіх або знайти за ім'ям, змінити вік, додати характеристику, видалити кота чи всі записи. Масове видалення потребує введення `ТАК`. Імена чутливі до регістру; пошук, оновлення та видалення за ім'ям обробляють перший відповідний документ. Вік — ціле невід'ємне число. Повторна характеристика не додається.

База за замовчуванням: `goit_ds_hw_03`, колекція: `cats`. Документ:

```javascript
{
  "_id": ObjectId("60d24b783733b1ae668d4a77"),
  "name": "barsik",
  "age": 3,
  "features": ["ходить в капці", "дає себе гладити", "рудий"]
}
```

## Завдання 2

```powershell
.\.venv\Scripts\python.exe scrape.py
.\.venv\Scripts\python.exe import_data.py
```

Скрапер проходить усі сторінки пагінації та завантажує біографії унікальних авторів. Результати зберігаються поруч зі скриптом як UTF-8 JSON: `authors.json` та `qoutes.json`. Написання `qoutes` збережене відповідно до умови.

Імпорт створює колекції `authors` та `qoutes` в Atlas. Індекси та upsert дозволяють повторювати імпорт без дублювання. Цитата посилається на автора повним ім'ям. Повторний імпорт оновлює наявні документи; записи, яких немає у файлах, не видаляються.

## Перевірка

```powershell
.\.venv\Scripts\python.exe verify.py
```

Інтеграційна перевірка виконує всі CRUD-операції в окремій тимчасовій колекції з випадковим ім'ям, після чого видаляє її. Потрібне доступне підключення MongoDB.

Локальна перевірка тієї ж логіки без Atlas:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe verify_offline.py
```

На момент виконання отримано 100 цитат і 50 авторів із 10 сторінок. Структура JSON та посилання на авторів перевірені. Дані імпортовано до MongoDB Atlas: база `goit_ds_hw_03`, колекції `authors` (50 документів) і `qoutes` (100 документів). У `cats` додано приклад кота `barsik` за умовою. Інтеграційні CRUD-перевірки у справжньому Atlas, локальні перевірки на mongomock і перевірка залежностей `pip check` пройдені.

## Подання

Архів `ДЗ1_Vadym.zip` містить код і JSON без `.env` та віртуального середовища. Перед поданням замініть `Vadym` у назві на повне ПІБ. Завантажте файли до публічного репозиторію `goit-ds-hw-03` і прикріпіть посилання та архів у LMS.
